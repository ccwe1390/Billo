## 2. Architecture & policy findings (outrank the fix list)

### P1 - Paid-call cost control is per IP only
The only guard on /extract, /explain, /packet is 40 requests per 60 s per
client IP (main.py:57-81); there is no global or daily cap, no response cache,
and the OCI budget alert is still unconfirmed (HANDOFF). Patching request
shapes one by one (H1 below) is a treadmill while any number of IPs can each
spend. Question for Evan: add a global ceiling on paid calls per hour/day (the
app answers "busy" past it) and set the OCI budget alert tonight?

### P2 - Who vouches for 31 languages?
27 interface files are unreviewed machine output; the 4 inline languages
(es/ar/zh-CN/zh-TW) are Claude drafts marked TODO-REVIEW and get no English
safety line. Workers found the primary button "Create my application packet"
rendered as a software "application package" in ~20 languages and the honest
"not eligible" message garbled in hu/fi/cs/th/ja/da/hr. The DROP list only
covered keys someone back-translated. Question for Evan: for the demo, keep
all 32 with a visible "machine translated" label and back-translate every
safety and call-to-action key tonight, or narrow the dropdown to reviewed
languages?

### P3 - The test suite cannot fail for browser bugs
tests/ never executes app.js (910 lines); its "JS tests" are regexes over the
source (test_api.py:201-208). 16/16 hand mutants in app.js (income x10, tax
answer inverted, Arabic/Hebrew dir flipped, stale-submit guard removed...)
passed all 5 test files. Question for Evan: add a small node test for the
pure browser functions (dollarsToCents, money, buildIcs, t/tSafe, dirOf) now,
or accept manual browser checks as the only browser evidence?
